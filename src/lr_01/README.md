## Краткий обзор
Ниже представлена примерная общая структура проекта без учёта вложенных каталогов. Состав каталогов и наличие конкретных файлов может отличаться в зависимости от специфики конкретной среды пользователя.

Структура проекта:
```sh
.
├──📁 coverage           # Отчёт о теством покрытии
├─*📁 node_modules       # Внешние зависимости (пакеты, библиотеки и т.п.)
├──📁 scripts            # Основная бизнес-логика
├──📁 styles             # Каскадные таблицы стилей
├──📁 test               # Тестовые сценарии и наборы
├── 🗎 .babelrc           # Конфигурация траспилятора
├── 🗎 .gitignore         # Игнорируемые файлы СКВ
├── 🗎 config.json        # Конфигурация проекта
├── 🗎 index.html         # Точка входа в проект
├── 🗎 package-lock.json  # Файл блокировки проекта
├── 🗎 package.json       # Манифест проекта
├── 🗎 README.md          # Описание проекта
├── 🗎 SETUP.md           # Установочные инструкции
└─> 🗎 todos.md           # Список заданий
```

*[СКВ]: Система контроля версий
- `─` обозначает элемент (каталог или файл)
- `<` обозначает элемент, игнорируемый СКВ по умолчанию;
- `*` обозначает элемент, игнорируемый СКВ (указан в файле *.gitignore*);
- `>` обозначает элемент, игнорируемый СКВ локально (на уровне проекта конкретного пользователя — для корректного использования и отображения должен быть указан в файле *.git/info/exclude*)
- `>>` обозначает элемент, игнорируемый СКВ глобально (на уровне системы конкретного пользователяa — для корректного использования и отображения должен быть указана в файле *~/.gitignore_global*)

## 3. Решение заданий

### 3.1 Задание 1

#### 3.1.1 Анализ исходных данных
Условие:
- в поля формы вводятся натуральные числа, представляющие длины сторон треугольника;
- после нажатия кнопки "Проверить" производится валидация входящих данных и определение вида треугольника по сторонам;
- на основании произведенного расчета выводится сообщение о том, какой это треугольник: равнобедренный, равносторонний или разносторонний;
- в случае ввода невалидных данных выводится сообщение об ошибке.

Исходные данные:
- $a, b, c \in \Bbb N$ — длины сторон треугольника.

Требуемый результат:
- $k \in \{ равносторонний, равнобедренный, разносторонний \}$ — вид треугольника по сторонам.

#### 3.1.2 Математическая формализация

В общем виде функция определения вида треугольника по сторонам может быть представлена следующим образом:

$$
f(a, b, c) =
\begin{cases}
k = равносторонний,  & a = b = c \\
k = равнобедренный, & a = b \lor b = c \lor a = c \\
k = разносторонний
\end{cases}
$$

#### 3.1.3 Алгоритмизация и программирование
Для реализации поставленной задачи разработано веб-приложение с использованием языка разметки HTML5+, стилизации при помощи CSS3+ и языка программирования ECMAScript (JS LS). Программа запускается в среде Node.js с помощью сценариев пакетного менеджера NPM. Весь программный код содержится в текущем каталоге, точкой входа в приложение является файла *index.js*. Основной программный код содержится в каталоге *scripts*, файлы стилей — в папке *styles*.

Запуск проекта осуществляется следующей командой:
```sh
$ npm start
```

В результате выполнения команды проект будет запущен в новой вкладке браузера.
